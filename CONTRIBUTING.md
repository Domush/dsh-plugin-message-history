# Contributing to dsh-plugin-message-history

Thank you for your interest in contributing!

## Development Guidelines

1. Ensure all code conforms to the local environment and standards.
2. Run tests with `npm test` before submitting changes.
3. Keep the build clean, zero warnings, zero stubs.

## Pull Requests

1. Fork the repo and create your branch from `main`.
2. Add comprehensive unit tests for any new features or bug fixes.
3. Update `CHANGELOG.md` with relevant details.
4. Ensure documentation (`README.md`) reflects your changes.
